# Changelog

## 0.1.2 preview

- Use the new TubePulse monogram in the Chrome toolbar, popup and project artwork.
- Add double-click Windows setup and use the public TubePulse Discord application by default.
- Add a Windows Lite download that uses an existing Node.js installation.

## 0.1.1 preview

- Add the TubePulse logo to the project and Chrome extension.
- Ask users to turn on sharing after choosing what Discord can display.
- Build a separate Chrome extension ZIP for store submission and document privacy and installation.

## 0.1.0 preview

- Add the Chrome extension, local Native Messaging companion and Discord Rich Presence integration.
- Add privacy controls, tab prioritization, playback tracking and recovery from interrupted connections.
- Add per-user Windows setup and removal, a ZIP packaging pipeline and Windows CI.
